## 實際改善

- 手機編輯與常用操作以 44×44 CSS px 為產品觸控目標；工具列保留換行與 8px 間隔。搜尋／檢視控制在窄螢幕分行，縮短裝飾封面，把空間留給內容。
- 重用既有色彩變數，分離 `--primary-ink` 文字／焦點色與主按鈕底色。深色連結及選中工具的色對由 2.92:1 提升至 8.84:1（一般表面）；主按鈕白字仍為 4.81:1。這是指定色對檢查，並非完整無障礙認證。
- 儲存中按鈕顯示「儲存中…」，狀態提供輔助技術公告及 `saving/dirty/saved`，文件／Markdown 切換提供按下狀態。
- 重載測試改為等待資料庫交易完成後的 `saved`，不再把按鈕停用誤認為完成。
